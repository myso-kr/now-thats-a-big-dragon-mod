# Now THAT'S a Big Dragon! — mod

Language patch, cheat widget, and full autoplay for the Steam idle game
*Now THAT'S a Big Dragon!* — injected over the Chrome DevTools Protocol,
**no game files modified**.

**[Documentation](https://myso-kr.github.io/now-thats-a-big-dragon-mod/)** ·

## What it does

| | |
|---|---|
| **Language patch** | Adds languages to the game's own settings screen — flag, name, time units and all. English and the game's own five are left untouched |
| **Cheat widget** (F8) | Resources, upgrades, game speed. Achievement submission blocked by default |
| **Autoplay** (F9) | Buys units and upgrades, fights, answers dialogue, repeats chapters — unattended |

language is added to the settings screen, so the choice stays the player's. A
language the game already ships (English, French, German, Portuguese, Turkish) is

*Steam share* is that language's share of Steam users, which is the order languages
are being added in. *draft* means machine-drafted and revised against reader
personas, but not yet checked by a native speaker — corrections are welcome as issues.

Thai is the one language drawn by the reader's own font rather than a pixel one: no
open pixel font covers the script at 6-10 px/em. The catalogue records that decision
so `check-fonts` can tell it apart from an oversight.

The game's own fonts are CC BY 4.0, so the European languages are drawn by *those*,
extended with the letters they lack — see `tools/extend-font.py`. Bundling any other
pixel font would leave one word in two faces: at this size nothing else matches a
6 px/em grid, so Czech `Poškození` would take its `š` from one font and its `o` from
another.

`locale/languages.json` carries the full catalogue of 26 planned languages; the table
above lists the ones actually bundled today.

## Quick start

Download a release, unzip, run `bigdragon.exe` with the game closed.
No runtime dependency — Node.js is not required.

```
bigdragon                  # follow the system language
bigdragon --lang ru        # force one
bigdragon --no-translate   # leave the game in its own language
```

From source:

```
npm start             # launch the game and attach
npm run doctor        # diagnose without launching the game
npm test              # 328 unit tests, no game needed
npm run check-fonts   # every character a translation uses is in its font
cargo test            # 117 unit tests, plus 7 against a real bundle
```

1.0.5b changed three things: the bundle hash, the version string, and one
dungeon-initialisation function. 1.1.0 added a save-data screen and a dungeon-artifact
feature — 49 new strings, one of them a thirteenth i18n namespace, which is what broke
the anchor that matched the namespace list end to end. It now matches by membership,
so the fourteenth will not.

This mod attaches to the bundle's internal structure, so a game update can break it.
`npm run doctor` tells you which anchor failed and what that breaks.

## Layout

```
src/          launcher (Rust) — runs outside the game
web/          scripts injected into the game page
patch/        bundle patching (Node reference implementation)
translations/ where each translation is written — one directory per language
locale/       what ships: translations, fonts and flags. Generated from translations/
tools/        things you run by hand
generated/    produced by tools/. Not committed
docs/         documentation (also the GitHub Pages source)
```

The launcher ships as Rust; `patch/` is the same logic in Node, and the two are
checked byte for byte against a real bundle. See
[docs/CONVENTIONS.md](docs/CONVENTIONS.md) for why.

## Contributing a translation

Everything under `locale/` is generated. The source is a plain Python table per
language under [`translations/`](translations/README.md), and one driver builds them all:

```
node tools/translate.js export pl > pl.tsv   # English, plus any existing column
#   ... fill in the third column, then move it into translations/pl/strings.py ...
python tools/build-translation.py pl         # writes locale/i18n.pl.json and the .ink files
node tools/check-fonts.js pl                 # every character is in the bundled font
npm run translations:check                   # the tables still reproduce what ships
```

The importer rejects a renamed or dropped `{{placeholder}}` and any key the game does
not have, and the exporter offers a row for every plural form the language actually
uses — four for Russian, six for Arabic — not only the two English has.

`translations:check` is the one that stops the two halves drifting: it runs every
table through the real importer, compares against the committed JSON, and fails
naming the key that would change. It runs in CI on every push.
