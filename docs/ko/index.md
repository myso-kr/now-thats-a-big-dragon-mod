# Now THAT'S a Big Dragon! — 모드

**[English](../)** · [GitHub](https://github.com/myso-kr/now-thats-a-big-dragon-mod)

스팀 방치형 게임 *Now THAT'S a Big Dragon!* 의 비공식 모드입니다.
세 가지 일을 하고, **게임 파일은 단 하나도 건드리지 않습니다.**

| | |
|---|---|
| **언어 패치** | 22개 언어, 각각 620개의 UI 문자열과 32개 대사 파일. 게임 자체의 6 px/em 격자에 맞춘 픽셀 폰트를 함께 실어 줍니다. 언어는 설정 화면에 *추가*되므로 선택은 플레이어의 몫입니다 |
| **치트 위젯** (F8) | 자원, 업그레이드, 게임 속도. 업적 전송은 기본으로 차단합니다 |
| **오토플레이** (F9) | 유닛과 업그레이드를 사고, 싸우고, 대사에 답하고, 던전을 돌고, 챕터를 반복합니다 — 사람 없이 |

> Valve 와도 아무런 관계가 없으며 승인이나 후원을 받지 않았습니다.
> 모든 상표와 저작권은 각 권리자에게 있습니다.
>
> **정식 구매한 게임이 필요합니다.** 이 저장소에는 게임의 원문이나 리소스가 들어
> 있지 않습니다. 본인의 게임 사본 없이는 번역이 적용되지 않습니다.
>
> **게임 파일은 수정하지 않습니다.** 런처는 메모리 안에서 응답만 바꿔 씁니다.
> 런처를 닫으면 게임은 그대로이고, 스팀 파일 무결성 검사도 통과합니다.
>
> **세이브가 깨질 수 있습니다.** 치트와 오토플레이는 게임이 예상하지 않은 상태를

> 조작하고 화면을 읽을 수 있습니다. 모드를 쓰는 동안에만 켜 두세요.
>
> **보증하지 않습니다.** 있는 그대로 제공합니다. 권리자의 요청이 있으면 이 저장소는
> 내려갑니다. (help@myso.kr)

## 설치

최신 릴리스를 내려받아 압축을 풀고, **게임을 끈 상태에서** `bigdragon.exe` 를
실행하세요. **따로 설치할 런타임은 없습니다** — Node.js 도 필요 없습니다.

[최신 릴리스 →](https://github.com/myso-kr/now-thats-a-big-dragon-mod/releases/latest)

게임 안에서는 **F8** 이 치트, **F9** 가 오토플레이입니다.
언어는 게임의 설정 화면에서 고릅니다.

이 모드는 게임 번들의 **내부 구조**에 붙기 때문에, 게임이 업데이트되면 깨질 수
있습니다. 뭔가 동작하지 않으면 이것부터 실행하세요. 게임을 켜지 않고 진단합니다.

```
npm run doctor
```

여섯 개의 앵커 중 무엇이 실패했고 그래서 무엇이 안 되는지 알려 줍니다.
이 출력을 이슈에 붙여 주시면 진단은 거의 끝난 셈입니다.

## 동작 원리

게임은 자기 리소스를 `gemshell://` 커스텀 프로토콜로 읽습니다. 런처는 그 응답을
Chrome DevTools Protocol 의 `Fetch` 단계에서 — 번들이 실행되기 전에 — 가로챕니다.
그래서 게임 입장에서는 파일이 원래 그랬던 것이 됩니다.

```
런처 ──CDP──▶ 게임 렌더러
  │                 │
  │  가로채는 것:   ├─ assets/index-*.js   → i18n 테이블 · 국기 · 라벨을 병합
  │                 ├─ assets/style-*.css  → @font-face 와 폰트 스택을 주입
  │                 ├─ dialogs/*.ink       → 번역한 대사를 응답
  │                 ├─ fonts/bd-*          → 폰트 바이트를 응답
  │                 └─ flags/*.png         → 국기 이미지를 응답
  │
  └─ 문서 로드 전 주입: 치트 위젯, 오토플레이 엔진
```

번들에는 세 개의 브리지를 심습니다. 메모리를 찌르는 대신 **게임의 진짜 명령**으로
상태를 읽고 쓰기 위해서입니다: `__bd_stores`, `__bd_dispatch`, `__bd_stats`.
게임 자신의 dispatch 를 거쳐 구매하면 잠금 해제도, 업적도, 부수 효과도 평소대로
동작합니다.
